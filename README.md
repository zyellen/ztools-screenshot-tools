# 截图工具箱 0.5.3

基于 Vue 3、Vite、TypeScript 的 ZTools 插件。

- 输入 `截图` / `截屏` / `screenshot`：主窗口隐藏后冻结所有显示器，拖拽框选。菜单位于选区下方，空间不足时移至上方，窄屏允许横向滚动。
- 菜单提供复制、保存、OCR、翻译、添加文本、滚动截图、悬浮显示、关闭。重新拖拽可改选区域。
- 添加文本：点击选区添加文本框，可编辑、拖动、删除，支持字号 ± 和五种颜色。“完成 / 取消”工具条位于原菜单位置；标注时 ESC 退出标注，其他时候 ESC 退出截图（滚动处理中等待完成）。
- OCR / 翻译在选区弹层展示，可复制结果及打开 Provider 配置。设置由父窗口读取并通过 URL 传入覆盖层。
- 悬浮显示创建可拖动、调整大小的置顶贴图，悬停显示复制、保存、关闭。滚轮按 1.1 倍放大/缩小，范围 0.1–5 倍，首次以适配窗口的显示比例为基准；双击图片恢复打开时窗口大小和适配显示。右下角百分比显示实际比例，2 秒后淡出。首次创建与滚轮缩放统一使用 pinSize，窗口先等比放大至满足最小 120×80，再整体等比缩至所在屏幕 bounds（屏幕限制优先）；保持自然宽高比，大图缩至屏内、小图允许留白。若宿主连续 2 次忽略或拒绝 resizeTo（成功一次即清零计数），则只缩放居中的图片，超出窗口部分隐藏。图片通过指针事件和父端 RPC 拖动，避免原生拖动区域吞掉滚轮和双击；持续悬停 250ms 聚焦和 ESC 关闭保留。
- 长截图默认选择 **手动滚动（我滚，自动拼接）**。点“开始”后自己用鼠标滚动目标窗口，插件只采集画面，不激活应用、不发送滚轮或按键。采集中选区内透明显示实时内容，选区外保持压暗，边框与尺寸保留；所有覆盖层开启鼠标穿透，可直接滚动目标窗口。预览面板显示帧数、已拼接高度和实时缩略图，可点“完成”拼接或“取消”放弃，面板聚焦时 ESC 取消。每 320ms 采集一次（截帧耗时超过间隔时顺延，不并发）；完整像素相同的帧丢弃并立即删除临时文件。捕获至少两帧后连续静止 2.5 秒自动结束，最多保留 60 帧。手动采集硬超时 45 秒，到点自动用已有帧拼接；只有一帧时，超时或点“完成”提示“未检测到滚动：只有一帧画面，未生成拼接图”。等待首次滚动同样受 45 秒硬超时限制。
- 复用 `scrollctl.html?preview=1` 与 `src/scrollctl/ScrollControl.vue` 作为 240px 宽预览面板，不新增 scrollpreview 入口。父端保存最多 60 张等比缩略帧，每次推送重新合成；预览与最终长图共用同一套全分辨率偏移：相邻原始帧通过 stitchOffsets 求偏移，预览仅按当前缩放比例映射偏移裁切，已拼接高度直接累计原始帧的新增高度，缩略图重绘至少间隔 150ms，通过 `__preview({frames,height,thumb,skipped,consecutive})` 推送（跳过计数立即推送并沿用缩略图），缩略图为 JPEG 0.7、宽度不超过 200px（超过 30 帧降至 140px），预览区最高 260px 并自动吸底。完成/取消复用既有 ctl-finish / ctl-cancel RPC。预览面板定位优先右、左、下、上，间隔至少 16px，放不下时放屏幕角落；降级控制条仍优先下、上、右、左，最后屏幕顶部居中并避开选区中心。与选区重叠时设为 80% 透明度，每次采集先 hide → 等待 120ms → 截帧 → 无焦点 show，避免浮窗进入长图；此时可能出现闪烁。首次显示通过 showInactive，或临时禁用 focusable 后 show 并恢复，保证点击前不抢焦点。宿主若两种 API 均不可用，会提示错误并恢复原窗口。
- 也可选择滚轮（自动，每轮 2 次、每次 3 行）、Page Down（自动，每轮 1 击）或 ↓ 方向键（自动，每轮 3 击）。三种自动方式保持最多 30 帧、连续两次无变化停止，前两帧完全相同时提示无滚动。滚轮作用于选区中心并还原光标，不依赖键盘焦点；按键方式会激活记录的目标应用。自动采集期间不要操作键鼠或切换窗口。
- 手动模式不隐藏覆盖层：父端调用所有 overlay 的 `setIgnoreMouseEvents(true,{forward:true})` 并推送 `__shotCaptureState('active')`，隐藏冻结图及菜单。若穿透或状态通知失败，console.error 记录并回滚所有覆盖层，降级到隐藏 overlay 与原紧凑控制条。贴图仍尽最大努力隐藏；自动三方式沿用原隐藏采集流程。完成、取消、45s 超时、异常均在 finally 关闭面板、关闭穿透并通知 idle、恢复隐藏窗口，再返回结果；超时后晚到的原生截帧同样删除。任意覆盖层可通过 scrollshot-cancel 取消当前会话；另一屏请求开始时会先取消旧会话并完成恢复，提示“另一块屏正在滚动截图，已为你取消，请重试”。控制面板按会话复用，关闭只清理自身。控制浮窗与选区重叠时，隐藏后等待 120ms 再截帧；手动结束或取消后销毁控制浮窗、恢复原窗口、清理所有临时帧。拼接使用信息量加权的两遍重叠检测；结果弹层支持滚动预览、复制、保存、悬浮显示和关闭。建议避开固定页头、滚动条，连续匹配失败会显示质量提示。
- `image-process` 图片入口仍在主面板提供 OCR、翻译、复制与保存。覆盖层冻结失败时保留主面板备用截图流程。

macOS 权限（系统设置 → 隐私与安全性）：

1. **屏幕录制**：为 ZTools 授权。冻结截图为空、全黑或捕获失败时提示并回退备用截图；主面板提供屏幕录制设置入口。
2. **辅助功能（仅自动滚动方式需要）**：为 ZTools 授权，允许模拟滚轮及备用滚动按键。备用按键方式中 osascript 返回无权限时，弹层显示“ZTools 需要辅助功能权限”和“去授权”按钮，打开辅助功能设置；授权后重新发起滚动截图。

Windows 上其余功能保留，点击滚动截图会提示“滚动截图当前仅支持 macOS”。不使用浏览器地址、网页自动化或浏览器重开，因此不再限于网页。

## 开发、验证与打包

依赖准备好后直接运行（无需安装新依赖）：

```sh
npm run dev
npm run build
node scripts/verify.mjs
npm run package
```

构建执行 vue-tsc 和 Vite，生成 `src-ztools/dist` 的主面板、覆盖层、贴图和滚动控制浮窗四个入口。验证脚本使用宿主桩覆盖：既有拼接与三种自动滚动回归、父子 RPC、权限错误、多屏生命周期；新增默认手动模式零合成输入断言、320ms 节奏、完整像素去重、静止 2.5s 且至少两帧、60 帧上限、完成/取消/单帧错误/异常清理、重叠浮窗 hide/capture/show、四向定位与负坐标双屏、初始贴图尺寸（40×40 → 120×120、100×50 → 160×80）、多屏 bounds 选择、宽高比误差 <1% 的缩放夹取、resizeTo 连续两次失败才降级及成功清零、45s 硬超时和 120ms 重叠等待。新增 TASK-006 验证覆盖：manual 不 hide overlay、穿透 true/forward 与 false、active/idle 通知、缺失/拒绝 API 与多屏部分失败降级、完成/取消/异常/硬超时恢复、迟到原生帧清理、预览节流/宽度/JPEG/帧数/拼接高度。FIX1 补充保留像素的三帧重叠与逐行接缝断言、31 帧降宽及 60 帧上限、idle 先于 hide、采集态点击穿透、跨屏取消/冲突恢复与重试、同会话面板复用及独立关闭。Vue 交互通过生命周期和窗口替身验证，测试不代替 ZTools 实机验收。

打包将 `src-ztools` 封装为 asar 并以 Brotli quality 5 压缩，输出 `release/ztools-screenshot-tools-0.5.3.zpx`，解压校验文件列表、HTML 入口及版本号。将该文件拖入 ZTools 安装。

## 结构与限制

- `src/App.vue`：主面板、设置、备用截图及入口注册。
- `src/shared/parentLink.ts`、`parentRequests.ts`、`childWindows.ts`：父子 RPC、子窗口映射与操作分发。
- `src/shared/overlaySession.ts`、`scrollCapture.ts`、`manualCapture.ts`、`scrollControl.ts`、`windowGeometry.ts`、`capturePresentation.ts`、`scrollPreview.ts`、`stitch.ts`：多屏生命周期、滚动截图、纯像素行重叠和无变化检测。
- `src/overlay/`、`src/pin/`、`src/scrollctl/`：框选、标注、结果、贴图和控制浮窗界面。
- `src-ztools/preload/services.js`：IPC 监听、文件与 macOS 截屏/滚轮/按键服务。

不支持向上回滚，请持续向下滚动；预览与最终图对上滚采用相同处理。固定页头、动画、按键不被目标应用接受、焦点位置不正确或内容尚未加载都可能影响拼接；本版不自动剔除固定页头。极端全屏选区可能没有空间显示尺寸和提示，重叠预览面板会在截帧时短暂隐藏。极长高分辨率图片受 WebView Canvas 尺寸及内存限制。未实现 Windows 滚动截图或滚动条拖动。

## 滚动截图焦点说明

macOS 默认手动滚动，用户自己操作鼠标，插件只观察画面。选择自动滚轮时：先把光标移到选区中心并滚动，滚轮作用于光标下的窗口，不需要键盘焦点，也不激活应用。每轮滚动后还原光标。选区中心必须位于可滚动内容中；固定面板或已到内容末尾会触发无变化提示。备用 Page Down / ↓ 方向键方式会激活记录的目标应用后按键；主窗口隐藏后以 100ms 间隔轮询前台应用，最多 1 秒，忽略空值和 ZTools。无法自动激活时提示在开始前手动点击目标窗口。

## 辅助功能权限

手动模式不要求辅助功能权限。自动方式请在系统设置 → 隐私与安全性 → 辅助功能中授权 ZTools，以便模拟滚轮及备用按键；所有方式截图均需屏幕录制权限。授权后若无滚动，确认选区中心位于可滚动区域且未到内容末尾；备用按键方式还需目标窗口有键盘焦点。滚动截图仅支持 macOS。

overlay 检测到窗口位置或尺寸异常时会补偿显示并重试窗口边界一次，诊断写入系统临时目录的 `ztools-shot/diag.log`，最多保留 200 行。贴图窗持续悬停 250ms 后聚焦，可按 ESC 关闭；提前移出会取消聚焦。


## 0.5.3 截图与拼接规则

区域截图在 preload 中将 DIP 的 x/y/宽/高四舍五入为整数，宽高至少 1；按 `getAllDisplays()` 的全部屏幕 bounds 并集裁掉超屏部分，保留负坐标。只向 `screencapture -x -R整数矩形` 传递确定参数，超时为 8000ms。失败信息包含 stderr（为空时用 message）与实际命令，console.error 同时记录矩形、exitCode、信号和超时状态。只有 stderr 含 `illegal option` 时去掉 `-x` 重试一次；最终失败返回 `{ok:false,error}` 并提示「请在系统设置 → 隐私与安全 → 屏幕录制 中允许 ZTools」，不做整屏像素裁剪降级。失败或超时会删除临时文件。

重叠检测保留原始物理尺寸和像素，每个物理行生成一条亮度签名，列间隔为 `max(1, ceil(width/256))`，每列取相邻两像素的亮度均值（0.299/0.587/0.114）。签名再与下一行平均，形成垂直两行模糊，容忍平滑滚动的亚像素重采样；不合并物理行，奇数位移仍可表示。每行记录亮度范围作为信息量，残差跳过信息量小于 10 的留白行，以及重叠区首尾两行，避免空白和帧边缘影响证据。

采用两遍搜索：只枚举至少 24 行的候选重叠，最大为较小帧高减 1。粗排每 6 条 informative 行取一条，至少需要 6 条采样证据；前 8 名逐行精算，至少需要 `max(32, ceil(overlap*0.15))` 条 informative 行。按信息行均差选最小值，接受条件为 mean ≤6、最大行差 ≤45。仅相差不超过 2 行、mean 差不超过 1 的近邻候选可取较大重叠；不以大重叠作为全局优先项。不足 24 行或信息量不足时返回 0，完整像素去重仍由 framesUnchanged 严格比较负责。

整数裁切不能还原亚像素滤波前的像素，验证按原页面相同相位重采样逐行比较。仅支持持续向下滚动，**不支持向上回滚**；固定页头、动画和大量重复内容仍可能影响匹配。

菜单宽度随内容变化，左边缘优先对齐选区；右侧空间不足时向左移动，保证至少 320px 可见宽度（小屏为屏宽减 16px）。最大宽度不超过剩余空间与屏宽减 16px 的较小值。默认 top 为选区底部 +8px；仅当再加菜单 44px 高度超出屏幕时，改为选区顶部 −52px。按钮保持单行，窄屏横向滚动；鼠标抬起且无标注、对话框或滚动设置面板时立即显示，采集时隐藏。尺寸标签保留在选区左上角外侧。

`node scripts/verify.mjs` 的 TASK-007-FIX4 自测使用确定性、不周期的完整页面（随机 14–29 行高、字块、边距、留白），不使用绝对行号通道。新增 1600×900、400×900 的六倍视口高页面，纯色行比例超过 50%，覆盖整数位移 1/5/13/20/37/58/91/300、0.5/0.4 亚像素、全异内容、每步 23px 的 10 帧整数链及累加 23.4px 的 20 帧亚像素链。整数链 offset 全对、总高严格相等；亚像素链每步 offset 与真实位移差 ≤1 行、总高与理论高度差 ≤帧数。两条链均检查每个接缝前后各 24 行，将非纯色行 SHA-256 映射到独立原页面位置并断言严格递增、无重复内容，纯色/留白行单独计数。其他既有逐行验证仍核对原页面 SHA-256 及像素内容。保留既有整数 1..110、40 帧链、预览和 A/C 行为回归；旧的极小重叠夹具按新证据下限放大，并单独验证不足 24 行拒绝匹配。1600×900 匹配用 performance.now 测 5 次中位数，算法目标 P50 ≤40ms，验证阈值为 80ms；前台应用轮询保留 3000ms 上限。原生权限与多屏显示效果仍需 ZTools 实机验收。

拼接以整行为单位，亚像素滚动单步存在 ±1 行量化误差，长链累积误差 ≤ 帧数；预览与最终图同源。


0.5.3 手动滚动安全垫：首帧正常接受；后续画面变化但无法识别重叠（offset=0）时，跳过该帧并立即删除临时文件，下一帧仍与最后一个已接受帧比较，避免把整帧重复追加。首次跳过提示“未能识别本次衔接，已跳过该帧以免重复”，每会话仅一次。帧数旁显示“已跳过 N 帧”；连续跳过 3 帧时显示提示色文字“滚动过快或内容过少，已跳过 N 帧，请放慢滚动”，匹配成功后恢复普通计数。跳过不占 60 帧上限，连续跳过 8 帧自动完成并拼接已接受帧；只有 1 帧时仍提示“未检测到滚动：只有一帧画面，未生成拼接图”。降级控制条同样显示跳过计数和提示。

纯色/留白超过约 80%、有效信息行不足、帧间亚像素重采样相位跳变时，重叠可能无法识别，手动模式会跳过帧。请放慢滚动、保留更多重叠并选择信息较多的区域；跳过无法补回未采集的内容。自动三种方式的判定逻辑保持原样，stitch.ts 算法未修改。

亚像素验证的 alpha 由每帧独立传入，支持随帧内行号变化；同相位要求 offset 与真值误差 ≤1 行，相位跳变允许安全返回 0，非零必须与真值误差 ≤1 行。新增 240 格相位跳变网格（2 种宽度 × 8 种位移 × 3 种留白遮罩 × 5 种相位），直接从原页面像素独立计算重采样行，结果保存在 `release/TASK-007-FIX4/phase-returns.json`。保留整数、逐行哈希、长链、接缝及 5 次中位数 <80ms 断言；驱动生产手动采集、拼接安全垫、预览和控制面板验证跳过、文件删除、连续终止、恢复衔接及整数回归。
